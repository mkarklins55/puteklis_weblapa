# Image Generation Instructions for puteklis.com

## Overview

These are English-language versions of existing images used in articles on puteklis.com.
Each image must be generated in English (any text visible in the image must be in English).
The visual style should match the existing Latvian versions — same composition, same mood, same layout.

## Style guidelines (apply to ALL images)

- Dark, cinematic tone — backgrounds in deep blues, teals, dark greys
- Photographic or high-quality semi-realistic illustration style
- If the image contains text labels, diagrams or infographics — all text must be in **English**
- No Latvian words anywhere in the image
- Aspect ratio: **16:9 landscape** (1280×720 px minimum, ideally 1920×800 for wide banner images)
- Save as `.jpg`, quality 85–90%

## Where to save the files

All files go in this folder on the server:
```
/images/raksti/
```

The naming rule is: original Latvian image + `-en` before the extension.
Example: `melnbalts-cilveks.jpg` → `melnbalts-cilveks-en.jpg`
